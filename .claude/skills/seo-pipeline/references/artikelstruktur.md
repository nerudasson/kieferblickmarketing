# Artikelstruktur

Die Artikelvorlage im WordPress-Plugin liefert Kopf, Autorenzeile, Inhaltsverzeichnis, Einstiegsleiter (Checkliste, Smile-Check, Ersttermin), Schlussmodul, Autorenbox und „Weiterlesen“ selbst. Der Text enthält diese Module nicht.

Frontmatter: title, slug, keyword, cluster, intent, autor (Alexander Andreev), meta_description (max. 155 Zeichen), status (entwurf), dazu die Kopfbox-Felder:
- kurz: drei Kernpunkte, je ein kurzer Satz
- ursache, behandlung, dauer, kosten: je ein bis zwei Sätze

Text (Markdown, wird in WordPress-Blöcke umgesetzt):
1. Antwort in den ersten zwei Sätzen (Einleitung ohne H1)
2. H2 passend zur Suchabsicht (Fragen als H2 wo sinnvoll), kurze Absätze (3–4 Sätze)
3. Lesbarkeit mischen: Fließtext, Aufzählungen, nummerierte Schritte (`kb-schritte`), eine Vergleichstabelle (`kb-vergleich`), ein bis zwei Merksätze (`kb-merksatz`), Hinweise (`kb-hinweis`)
4. Was dagegen spricht / Nachteile ehrlich
5. Kosten oder Ablauf konkret, wenn das Keyword danach fragt (nur Zahlen aus `kontext/angebot-und-preise.md`)
6. Wann ein Termin sinnvoll ist (ohne Druck, ohne Diagnose)
7. FAQ (3–5 Fragen, kurz, `kb-faq`)
8. Fazit mit kurzer Schlusszeile (`kb-cta`)
9. Quellen (`kb-quellen`): Autoren, Titel, Zeitschrift, Jahr, Link

Länge nach Intent: Info 800–1.200 Wörter, Kosten/Vergleich 1.200–1.800. Interne Links: 2–4 auf Artikel desselben Clusters, 1 auf die Leistungsseite.
