# Testfälle meta-ads
Muster in diesem Ordner sind **Testmuster**, keine echten Kampagnen. Befehle vom Projektstamm. `T=.claude/skills/meta-ads/tests`

1. **Sauberes Muster besteht:** `META_CONFIG=$T/muster-config.json python3 -I .claude/skills/meta-ads/scripts/anzeigen_check_meta.py $T/muster-gut.json`
   Erwartung: „OK (0 hart, 0 weich)“, Exit-Code 0.
2. **Budget-Lücke wird gemeldet:** dieselbe Prüfung ohne `META_CONFIG` (echte Konfiguration, Budget 0). Erwartung: genau ein HART „Kein Monatsbudget für „kalt““.
3. **Fehler werden gefunden:** Prüfung von `$T/muster-fehler.json` mit `META_CONFIG`. Erwartung: Exit-Code 1, etwa 40 HART-Treffer, darunter: status ACTIVE, fehlende Pflichtfelder, Budget über Deckel, Kunden nicht ausgeschlossen, Hauptaufruf „basiskurs“ (nie direkt zu einem bezahlten Kurs), Nebenaufruf passt nicht zur Stufe, mehr als zwei Aufrufe, Stock-Bild, Masterclass, Webinar, Functional, Garantie, Rabatt, Dringlichkeit, Umsatzversprechen, Ausrufezeichen, Duzen, „bisherige Behandlung falsch“, Button BOOK_NOW, http-Link, fremde Domain, UTM-Verstöße (Großschreibung, Umlaut, falsche Werte), doppelte Anzeigennummer, Teilnehmerstimme ohne Einwilligung.
4. **Freitext-Prüfung:** `python3 -I .claude/skills/meta-ads/scripts/anzeigen_check_meta.py --text "Masterclass mit Rabatt, nur noch heute!"` → HART; mit „Ihr erster Fall, sicher und begleitet, vom Biss her.“ → OK.
5. **Trockenlauf Anlegen:** `META_CONFIG=$T/muster-config.json python3 -I .claude/skills/meta-ads/scripts/meta_push.py $T/muster-gut.json`. Erwartung: Plan als JSON, alle Objekte `PAUSED`, Hinweise „MANUELL“ (Video, Bild, Detailtargeting), „nichts angelegt, kein Netzwerkzugriff“.
6. **Sperren beim Anlegen** (`--anwenden`): (a) mit echter Konfiguration → Abbruch durch die Prüfung (Budget 0). (b) mit `muster-config.json` ohne Umgebungsvariablen → „Umgebungsvariable(n) fehlen“. (c) mit `ads.schreibzugriff` false → „Abbruch: ads.schreibzugriff ist false“. Erwartung jeweils: kein Netzwerkzugriff.
7. **Voller Lauf gegen den Testserver:** `python3 $T/fake_graph.py 8765 /tmp/fake.log &`, dann `--anwenden` mit `META_CONFIG=$T/muster-config.json META_GRAPH_BASE=http://127.0.0.1:8765 META_PROTOKOLL=/tmp/p.md META_ADS_ACCESS_TOKEN=x META_AD_ACCOUNT_ID=1 META_PAGE_ID=2 META_PIXEL_ID=3` und einer Kopie des Musters mit `video_id` in Anzeige 1 und `bild_datei` (`$T/pixel.png`) in Anzeige 2. Erwartung: Server-Log zeigt nur POST auf campaigns/adsets/adcreatives/ads/adimages, jedes mit `status=PAUSED` oder ohne Status (Creatives, Bilder), nie ACTIVE; Protokoll mit vier Zeilen; Token nirgends in Protokoll oder Log. Ein zweiter Lauf bricht ab: „Kampagne … existiert schon“.
8. **Video ohne `video_id`:** `--anwenden` bricht **vor** dem ersten Aufruf ab („video_id fehlt“), der Server sieht keine Anfrage.
9. **Auswertung:** `python3 -I .claude/skills/meta-ads/scripts/kennzahlen.py $T/kennzahlen-eingabe.json`. Erwartung: Zeile je Anzeige, Summe, Hinweis „Nur 22 Leads: Tendenz“, „Noch kein Käufer“, LinkedIn-Zeile wird ignoriert, Anzeige ohne Ausgaben wird gemeldet.
